# Site Printikos

Página única estática (HTML + CSS + JS, sem build). Abrir `index.html` no browser ou publicar a pasta em GitHub Pages / Netlify.

## Antes de publicar
- `index.html`: substituir `+351 9XX XXX XXX` e `[email a definir]` pelos contactos reais.
- No `<script>`, preencher `CONTACT.whatsapp` (ex.: `"351912345678"`) para ativar o botão "Abrir no WhatsApp".
- Confirmar as afirmações do site: "até 4 cores por peça" e "de 1 a 100+ unidades".
- Juntar fotos reais dos protótipos aos cartões de produto (neste momento usam ilustrações).
